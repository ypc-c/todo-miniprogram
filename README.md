# 待办清单小程序（todo-miniprogram）

一款**纯本机、离线可用、零注册**的微信小程序待办清单。数据完全保存在本机，不上传、不同步、无第三方 SDK，打开即用。

## 功能特性

- **清单管理**：任务新增 / 编辑 / 删除 / 完成切换，支持按「全部 / 今日 / 逾期 / 标签」筛选与关键词搜索
- **智能快捷添加**：自然语言输入（客户端规则引擎，离线可用），如「明天下午3点 高优先级 工作：交周报」自动解析出时间、优先级与分类
- **任务全字段**：截止日期、优先级（高/中/低）、标签分类（工作/学习/生活，可自定义）、子任务、备注
- **重复任务**：支持每天 / 每周 / 自定义重复规则，完成后自动生成下一次实例
- **附件**：图片 / 语音，存储于小程序本地文件目录（不占用 10MB KV 上限）
- **地理位置**：任务可附带位置信息（需授权，仅作为任务属性本地保存）
- **分类管理**：自定义标签颜色与名称
- **数据导出**：一键导出 JSON 备份，防止本机数据丢失
- **应用内提醒**：打开小程序时对到期 / 逾期任务高亮、角标提示
- **桌面入口引导**：引导添加到桌面 / 我的小程序

## 技术栈

- 原生微信小程序（无框架、无 npm 依赖、无云开发）
- 本地存储：`wx.setStorage`（任务数据）+ `wx.getFileSystemManager`（附件文件）
- 自然语言解析：客户端规则引擎（中文时间词 / 正则匹配），纯离线

## 快速开始

1. 克隆本仓库

   ```bash
   git clone https://github.com/ypc-c/todo-miniprogram.git
   ```

2. 用**微信开发者工具**导入该目录
3. 项目 appid 已设为 `touristappid`（游客模式可直接预览）；如需真机调试，在 `project.config.json` 中替换为你自己的 appid
4. 编译运行即可，无需安装任何依赖

## 数据与隐私

- 所有数据仅保存在本机（微信本地存储与用户文件目录），无任何网络请求
- 换机 / 重装微信 / 清理小程序数据会导致数据丢失，请定期在「设置」中导出 JSON 备份
- 提醒为应用内提醒（小程序无系统级后台推送能力）
